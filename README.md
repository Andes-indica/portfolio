# Prajwal G V — Portfolio

A concise, recruiter-focused portfolio for my software engineering work, open-source contributions, and technical interests.

**Live:** [prajwal-g-v.vercel.app](https://prajwal-g-v.vercel.app)

## Highlights

- Selected work: PMS–OMS, Darukaa Earth, and the Indian Market Risk Engine
- Four merged contributions to [Noveum/orbit](https://github.com/Noveum/orbit)
- Direct links to source code, the deployed Darukaa product, résumé, LinkedIn, GitHub, and CodeChef
- Responsive light/dark design with concise copy and accessible navigation
- SEO metadata, structured data, sitemap, and robots configuration

## Stack

Next.js 15, React 19, TypeScript, Tailwind CSS, and `next-themes`.

## Run locally

```bash
bun install
bun run dev
```

Then open [http://localhost:3000](http://localhost:3000).

## Validate

```bash
bun run typecheck
bun run lint
bun run build
```

Portfolio content is maintained in `src/data/portfolioData.ts`.
